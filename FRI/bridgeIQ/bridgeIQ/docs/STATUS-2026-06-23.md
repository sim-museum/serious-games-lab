## This session

### Claude annotation from the score table — fixed + reworked
- **Root-cause bug fixed**: the score-table "annotated transcript" *always*
  reported "Claude request cancelled" and discarded the result. Cause: closing
  the progress `QDialog` calls `reject()` (Qt's `closeEvent`), emitting
  `rejected`, which was wired to the Cancel handler — so every *successful* run
  marked itself cancelled at teardown. Guarded with a `done` flag set before
  `close()`. (`_run_claude_with_dialog`, ui/main_window.py.)
- **Scoped Claude critique**: the single heavy 5-task trick-by-trick prompt
  (900s timeout) is replaced by a **Claude critique ▾** menu with four scopes —
  Quick verdict (180s), Bidding only (360s), Card play only (360s), Full
  critique (900s). The small scopes ask for far less and return fast instead of
  timing out. (ui/dialogs/compare_replay.py.)
- **biq's own offline comparison**: new **biq comparison** button — a
  deterministic side-by-side write-up of the two rooms (contracts, result, IMP
  swing via cross-IMP of the score difference, opening leads, and a
  call-by-call auction-divergence table with differences highlighted). Instant,
  no Claude, works with Claude disabled.
